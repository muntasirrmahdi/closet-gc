# Contributing to Closet GC

Thank you for your interest in improving Closet GC.

## How to Contribute

1. **Report Bugs**: Open an issue using the Bug Report template.
2. **Suggest Features**: Open an issue using the Feature Request template.
3. **Pull Requests**:
   - Fork the repository.
   - Create a new branch for your feature or fix.
   - Keep changes focused and minimal.
   - Open a PR with a clear description.

## Code Standards

- Web: vanilla HTML/CSS/JS, no frameworks, no build steps.
- CLI: Python 3, stdlib only (sqlite3, argparse).
- Keep the web version a single self-contained HTML file.
- localStorage keys use the `closetgc_` prefix.
